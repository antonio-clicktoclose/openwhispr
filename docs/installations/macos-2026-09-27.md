Local Whisper large-v3-turbo and Qwen3.5 2B cleanup models were also installed. Synthetic English and Portuguese local transcription tests passed, as did a local cleanup test. Live local dictations completed during setup.

Selected preferences, dictionary entries and text replacements were migrated from Wispr Flow. Exact shortcut parity is incomplete because this release does not support the same Fn combinations. The shared internal setup note records the chosen shortcuts and recovery steps.

## Operating notes

OpenAI dictation sends audio to OpenAI and incurs API charges. Local transcription remains available in Settings. Review recording and transcript retention to suit the device's use.

The app stores history in a local SQLite database. Treat application data as private. The source review found weakened isolation in the control-panel window (`sandbox: false`, `webSecurity: false`); notarization does not establish that the application is free of vulnerabilities.

Keep credentials, transcripts, dictionary contents, account details and app-data backups out of this repository. Installing or updating the application does not require merging this documentation PR.
